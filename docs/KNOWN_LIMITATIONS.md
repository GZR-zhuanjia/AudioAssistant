# 已知限制和未完成事项

## 验证边界

本仓库已实现真实处理代码，并通过独立 JVM 和宿主机 Native 测试；尚未完成 Android Studio 全工程编译、arm64 NDK 交叉编译、安装或 Android 16 实机测试。宿主机的成功不代表 Android ABI、Media3/Compose、厂商解码器和 16 KB 打包已经正确。请完成 [BUILD_AND_TEST.md](BUILD_AND_TEST.md) 中的清单。

## 第一版范围

* UI 将两个独立模块作为首页入口卡片切换，歌曲列表、选中歌曲裁剪和导出面板在同一滚动页面内；尚未拆为独立导航目的地。排序支持长按拖动柄和上下移动按钮；拖动过程中显示临时顺序，松手后才保存，取消恢复原顺序。
* 保存最近一个编辑项目；没有多项目库、项目 JSON 导入导出界面或版本迁移向导。撤销/重做是每首歌的进程内历史，不持久化历史栈。自动保存和生命周期时补写仍无法保证突然断电/强杀前最后一次输入落盘。
* 波形是分窗口峰值，不是采样编辑视图。支持概览、详细时间刻度、选区、缩放及平移；没有专业编辑器的吸附、节拍检测、零交叉吸附。详细波形使用移动指针，未实现优先建议的固定中央指针自动跟随模式。
* 没有多轨混音、交叉淡化或专业时间拉伸。可选 5 毫秒淡入淡出应用在每首剪辑后歌曲的开头/结尾，不作用于同一首歌内部每个删除连接点；不能保证消除全部爆音。
* 输出固定 M4A / AAC / 48 kHz / 双声道 / 192 kbps 目标；支持调节目标响度及手动 ±6 dB，不提供其他编码格式或任意导出参数 UI。界面中的码率是目标，AAC 实际平均码率会变化。

## 试听差异

* Media3 直接播放源文件及 clipped playlists，使用微秒剪切参数；播放位置观测仍受播放器时间接口和解码器精度限制。预览不是采样级精确，片段间可能有解码延迟、间隙或不同于最终文件的连接听感。
* 自动响度均衡和淡入淡出仅在 FFmpeg 导出链生效。试听只做手动 PCM 音量，正增益时有饱和限制，不能用它判断最终 LUFS、真峰值或动态响度处理效果。界面已标明差异。
* 没有专门缓存并渲染短剪口以提供更精确的连接点预览。源文件能被 FFmpeg 解码，也可能不被 Media3/该手机的音频解码器支持；此时仍可导出，但原文件试听会报错。

## 响度与 Native 处理

* 同一首歌曲的所有保留片段整体测量，使用 loudnorm 实际 measured 参数。缓存按精确拼接 PCM 内容及有效目标参数的 SHA-256 保存；命中仍需解码/拼接以计算相同内容哈希，不会跳过全部解码。
* 极短内容、静音或限制严苛的音频不一定达到 -16 LUFS。静音的无穷测量值不会作为非法参数传给第二遍；转用动态 loudnorm。无法同时满足响度/峰值时，FFmpeg 会采用动态归一化；不承诺每首歌最终 LUFS 严格相等。
* 正手动增益通过提前预留真峰值余量再增益实现，可能使响度低于目标；超出 loudnorm 可用峰值预算时明确失败。用户手动增益本来就会改变归一化后的相对响度。
* dBTP 目标针对编码前处理。AAC 有损编码可能引入解码后峰值过冲，尚未实现编码后重新测量并迭代降低电平的保护流程。关闭自动均衡后，正手动增益可能削波。
* 抽取支持兼容 AAC/ALAC 的直接封装。其他音轨统一转 AAC；不保留多音轨、原视频章节、封面或复杂元数据，也不提供音轨选择 UI。受精简编译限制，并非所有输入编解码器都可用。
* Native 时间边界按解码采样裁剪再重采样；无可靠 seek 时间戳的远端区间、动态改变采样率/声道布局的特殊流、严重损坏或错误时长的文件可能失败，不伪造成功结果。
* loudnorm 统计依赖 FFmpeg 7.1.1 滤镜析构时的 JSON 日志，集中封装并使用单任务、滤镜单线程和 thread-local 捕获。升级 FFmpeg 后必须复测日志字段和行为。日志回调是进程全局的；本应用不同时集成另一套 FFmpeg 客户端。

## 存储和长任务

* 输入复制为私有不可变快照，占用额外磁盘；删除卡片不会立即删除快照，以免破坏仍共享源内容的项目/任务。暂无存储管理界面；可以在系统应用设置清除应用数据，但会同时删除项目和私有输出。请先另存重要输出。
* 统一双声道 float PCM 约占 23 MB/分钟，处理中还需保留原始和已处理数据及最终输出，长项目需要足够空间。尚未提供可靠的空间预算预估 UI；写入错误会结束任务并清理正常异常路径的临时文件。
* 进程内取消/失败通过 RAII 清理 PCM 和不完整输出。系统强杀不会执行析构；下次读取项目会清理超过 24 小时的 `.partial` 和 `audio-job-*` 遗留工作目录。已完成输出不会被自动删除。
* 没有前台服务、后台通知或可恢复任务队列。离开页面/锁屏不承诺长任务存活；首版请保持应用在前台完成导出。系统停止应用后需重新启动任务。
* 视频任务队列和完成结果路径保存在当前 ViewModel，不是持久化任务数据库；进程重启后需重新选择视频。歌曲项目及源快照会恢复。
* 导入后的外部源变化不会悄悄替换已剪辑内容，需重新导入形成新快照；没有自动关联外部文件更新或“重新链接源文件”界面。源私有快照丢失时会明确报错。

## 本地必须复核

FFmpeg 动态库及所有其他 `.so` 的 16 KB ELF/zip 对齐、Gradle/Compose API、Media3 PCM 处理、SAF provider 行为、Android 16 音频焦点、JNI 取消竞态、长音频性能，以及真实录屏的音轨时间戳都必须在本地验证。LGPL 对应源码和替换库权利见 [FFMPEG_LICENSES.md](FFMPEG_LICENSES.md)。
